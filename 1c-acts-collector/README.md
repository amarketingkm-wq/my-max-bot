# 1C Acts Phone Collector

Скрипт для Windows: проходит по открытому отчёту **«Обращения клиентов. Акты оценки»**, из каждого **Акта оценки** забирает сумму и телефон клиента.

## Сценарий

1. В списке открывает текущий `Акт оценки …` (Enter).
2. Читает поле **«Общая сумма выдаваемая клиенту на руки»** (OCR).
3. Фокусирует **«Залоговый билет»** → `Ctrl+Shift+F4` (открыть ссылку).
4. В залоговом билете открывает **«Клиент»** (кнопка «две клеточки» / `Ctrl+Shift+F4`).
5. В карточке жмёт кнопку показа у **«Телефон +7»**, считывает номер OCR (копирование недоступно).
6. Закрывает карточку → билет → акт, стрелка вниз к следующему акту.
7. Пишет результат в `output/acts_phones.csv`.

## Можно ли работать в других программах

**Да, с условием:** окно 1С должно оставаться **видимым** (лучше второй монитор), не свёрнутым.

Скрипт на доли секунды забирает фокус у 1С на клик/горячую клавишу, затем можно снова работать в другом приложении. Полностью «в фоне без активации окна» у управляемых форм 1С обычно нестабильно.

Горячие клавиши:

- `F8` — пауза / продолжить
- `F9` — стоп

## Установка (на ПК с 1С)

```bat
cd 1c-acts-collector
py -3 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Нужен [Tesseract OCR](https://github.com/UB-Mannheim/tesseract/wiki):

- поставьте русский язык (`rus`)
- если не в PATH — пропишите путь в `config.json` → `ocr.tesseract_cmd`, например:
  `C:\\Program Files\\Tesseract-OCR\\tesseract.exe`

## Запуск

1. Откройте в 1С отчёт **«Обращения клиентов. Акты оценки»**.
2. Поставьте курсор на первый нужный акт (`Акт оценки …`).
3. Запустите:

```bat
python probe_windows.py
python run_collector.py
```

Для проверки на 1–2 актах в `config.json` поставьте `"max_acts": 2`.

## Результат

`output/acts_phones.csv`:

| collected_at | act_title | amount | phone | ticket_title | status | error |
|---|---|---|---|---|---|---|

`output/processed.txt` — уже обработанные акты (чтобы не дублировать).

## Если промахивается по кнопкам

```bat
python calibrate_click.py "Залоговый билет"
```

Наведите мышь на нужную кнопку → `F7` (координаты в `output/calibration.json`).  
Шаблоны кнопок лежат в `templates/` (можно переснять со своего экрана).

## Важно

- Это UI-робот, не интеграция с базой 1С. Смена формы/темы/масштаба может сбить клики.
- Телефоны — персональные данные: CSV храните локально и по правилам компании.
- Если админ 1С даст отчёт/запрос «акт → телефон», тот путь надёжнее этого скрипта.
